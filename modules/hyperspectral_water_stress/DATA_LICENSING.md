# Data Licensing and Attribution

## Dataset source

The hyperspectral data used in this module is the **UC-HSI Crop Variety Dataset — Groundnut Water Stress component**, provided by **IIT Hyderabad TiHAN** (Technology Innovation Hub on Autonomous Navigation, Indian Institute of Technology Hyderabad).

This dataset was shared with Aganitha Space Technologies for research purposes. **Aganitha is not the originator or rights-holder of this dataset.**

## What this repository contains

This repository contains:

- ✅ Source code authored by Aganitha Space Technologies (`pipeline.py` and related scripts)
- ✅ Methodology and results documents authored by Aganitha Space Technologies (`README.md`, `methodology.md`)
- ✅ Figures and visualisations generated by Aganitha Space Technologies from the analysis (in `figures/`)
- ✅ Numerical results, metrics, and configuration (`results.json`)

## What this repository does NOT contain

This repository **does not contain**:

- ❌ The raw hyperspectral data files (`X_GN_31Dec.npy`, `y_GN_31Dec.npy`) — these remain the intellectual property of IIT-H TiHAN
- ❌ Trained model weights derived from the dataset — these are held privately by Aganitha pending explicit redistribution permission from the dataset originator

## How to obtain the data

To reproduce this work, the underlying dataset must be obtained directly from the originator:

**Contact:** IIT Hyderabad TiHAN
**Dataset:** UC-HSI Crop Variety Dataset — Groundnut Water Stress component
**Files required:** `X_GN_31Dec.npy`, `y_GN_31Dec.npy`

Researchers and reviewers should approach IIT-H TiHAN through their official channels. Aganitha will not redistribute the dataset.
